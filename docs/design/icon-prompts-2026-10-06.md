# 하늘키보드 아이콘 제작 프롬프트 3안

기준일: **2026-10-09** · 아래 프롬프트 작성일: 2026-10-06 · macOS 전용 한국어 입력기 · 제품 기준 커밋 `cdd26cd`.

> 보관된 과거 탐색 문서다. 현재 앱 아이콘은 `Resources/Brand/HaneulKeyboard-Main.png`, 메뉴바는 `Resources/Brand/HaneulKeyboard_Menu_Icon_2@2x.png`다. 아래 구름 후보 원본은 2026-10-09 사용자 요청으로 삭제했다. 현재 제작 지시로 사용하지 않는다.

## 당시 정해진 것

- 메뉴바 아이콘은 사용자가 고른 **3번 ‘구름 ㅎ’**다. 이 문서는 그 형태와 어울리는 **큰 앱 아이콘**을 새로 만드는 프롬프트다.
- ‘하늘’이라는 이름, 구름, 한글 자음 **ㅎ**를 공통 요소로 삼는다. 새 앱 아이콘은 사용자가 생성한 후보를 보고 최종 선택한다.
- 앱 아이콘, 메뉴바 아이콘, 시스템 입력 소스 아이콘은 서로 다른 크기와 표시 규칙을 사용한다. 큰 컬러 그림 하나를 모두에 그대로 줄여 쓰지 않는다.
- 메뉴바 원본: `work/onboarding-preview/menu-icons/haneul-cloud.svg`. 현재 큰 앱 아이콘: `Resources/AppIcon.icns`.

## 크기와 파일 형식

| 용도 | 제작 크기 | 전달할 파일 | 확인할 것 |
|---|---|---|---|
| 앱 아이콘: Finder·Dock·설정·시작하기 | **1024×1024 px**, 정사각형. 여유가 있으면 2048×2048 원본도 보관 | PNG, sRGB. 가능하면 배경과 심볼을 나눈 원본도 보관 | 1024에서 예뻐도 32·64px에서 형태가 읽혀야 한다 |
| 메뉴바의 구름 ㅎ | 벡터 원본. 현재 시안 표시 크기는 **18×18pt** | SVG 또는 PDF. PNG라면 18×18과 36×36(@2x) | 검정 단색 + 투명 배경. 어두운 배경에서는 시스템이 밝게 표시할 수 있는 템플릿 방식 |
| macOS 입력 소스의 ‘하늘’ 표시 | 배포본 2026.08은 **16×16, 32×32(@2x)**. 이번 단색 수정 후보는 **22×16, 44×32(@2x)** | 단색 벡터/PNG 및 입력기 설정 | 두 글자를 작은 칸에 넣으면 작아진다. 최종 크기는 메뉴·어두운 화면·파란 전환 표시의 실기기 확인 후 결정 |

1024×1024는 Apple 앱 아이콘 원본 규격에 맞춘다. 메뉴바 18pt는 이번 하늘키보드 시안의 설계값이며 모든 메뉴바 앱의 의무 규격이라는 뜻은 아니다. Apple의 현재 도구는 레이어를 나눠 재질을 구성할 수 있지만, 이 프로젝트는 현재 `.icns`를 사용한다. 생성된 PNG를 바로 완성된 배포 아이콘으로 취급하지 않고, 적용할 때 크기별 자산과 가장자리를 정리한다. [Apple 앱 아이콘 안내](https://developer.apple.com/design/human-interface-guidelines/app-icons), [아이콘 구성 안내](https://developer.apple.com/documentation/xcode/configuring-your-app-icon).

## 사용하는 방법

아래 프롬프트 중 하나를 통째로 복사해 요청한다. 한 번에 한 아이콘만 만든다. 마음에 든 결과가 나오면 같은 이미지를 기준으로 ‘구름을 조금 단순하게’, ‘ㅎ를 더 굵게’처럼 한 가지씩 수정한다.

한글 글자가 틀리면 그림 전체를 버릴 필요는 없다. 구름과 배경을 확정한 뒤 **ㅎ는 정확한 벡터 글자로 다시 얹을 수 있다.** 입력기라는 뜻을 자세한 키보드 그림이나 작은 글자에 의존하지 않는 것이 좋다.

## 프롬프트 1 — 맑은 유리 구름

방향: 현재 시작하기 화면과 잘 어울리는 차분한 유리 재질. 세 안 중 먼저 시도할 추천안.

```text
macOS 전용 한국어 입력기 ‘하늘키보드’의 앱 아이콘을 만들어 주세요.

1024×1024 픽셀의 정사각형 앱 아이콘 원본 한 장입니다. 앱이 놓인 화면이나 제품 목업을 그리지 말고, 정면에서 본 아이콘 아트워크만 보여 주세요.

중앙에는 단순하고 부드러운 구름 심볼 하나를 놓습니다. 구름 안에는 한글 자음 ‘ㅎ’ 하나만 크고 또렷하게 넣습니다. 정확히 ‘ㅎ’이며, 영문 H나 다른 한글로 바꾸지 마세요. 작은 세로 획, 그 아래 가로 획, 아래쪽의 둥근 고리라는 구조를 유지합니다.

배경은 맑고 밝은 하늘색에서 옅은 청록색으로 아주 부드럽게 이어지게 합니다. 구름은 옅은 우윳빛 유리 재질로, 가장자리에 절제된 빛 반사와 얕은 두께를 주세요. ㅎ는 유리 안에서도 충분히 진하고 선명하게 읽혀야 합니다. 투명한 재질의 느낌 때문에 심볼이나 글자가 흐려지면 안 됩니다.

전체 인상은 편안하고 정돈된 Mac 유틸리티입니다. 구름과 ㅎ는 중앙에 균형 있게 배치하고, 가장자리에는 균일한 여유를 둡니다. 배경은 정사각형 전체를 채우며, 바깥 모서리를 미리 잘라 투명하게 만들지 마세요. 실제 앱 모서리와 크기별 처리는 나중에 할 것입니다.

32픽셀로 줄여도 구름과 ㅎ가 구분될 만큼 큰 형태와 충분한 대비를 사용하세요. 강한 빛 번짐, 무지개 테두리, 렌즈 플레어, 복잡한 키보드, 작은 키캡, 사진 같은 하늘, 다른 글자, 앱 이름, 워터마크, 테두리 밖 그림자는 넣지 마세요.

PNG, sRGB, 1024×1024로 출력해 주세요.
```

## 프롬프트 2 — 단정한 평면 심볼

방향: 유행을 덜 타고 작은 크기에서 가장 명확한 안. 나중에 벡터로 다듬기도 쉽다.

```text
macOS 전용 한국어 입력기 ‘하늘키보드’의 미니멀한 앱 아이콘을 만들어 주세요.

1024×1024 픽셀, 정사각형, 정면, 아이콘 한 개만 출력합니다. 제품 화면이나 여러 후보를 나란히 놓은 보드는 필요하지 않습니다.

큰 구름 모양 하나와 그 안의 한글 자음 ‘ㅎ’ 하나로 구성합니다. 정확히 ‘ㅎ’만 사용하고 영문 H, ㅇ, 앱 이름 등 다른 글자를 추가하지 마세요. 구름은 둥근 굴곡 세 개 정도로 단순화하고, 내부 ㅎ와 바깥 곡선이 서로 닿지 않도록 충분한 공간을 주세요.

그래픽은 매끈하고 또렷한 평면 벡터 스타일입니다. 배경은 아주 옅은 하늘색, 구름은 짙은 남색, ㅎ는 밝은 색으로 구름에서 명확히 구분되게 합니다. 색은 세 가지 이내로 제한합니다. 색을 제거하고 흑백으로 바꾸어도 형태와 대비가 유지되어야 합니다.

중심 심볼은 너무 작지 않게 배치하고, 좌우·상하 여백을 균형 있게 맞춥니다. 정사각형 배경은 끝까지 채우고 바깥 모서리를 미리 자르지 마세요. 32픽셀에서도 선이 사라지지 않을 만큼 굵고, 원과 곡선의 두께는 시각적으로 균일해야 합니다.

입체감, 그라데이션, 유리 반사, 그림자, 질감, 가는 장식선, 작은 키보드, 얼굴, 캐릭터, 작은 글씨, 워터마크는 넣지 마세요. 친근하지만 유아용 앱처럼 보이지 않도록 해 주세요.

PNG, sRGB, 1024×1024로 출력해 주세요. 벡터 출력이 가능한 도구라면 동일한 형태의 편집 가능한 SVG도 제공해 주세요. PNG만 지원한다면 PNG로 충분합니다.
```

## 프롬프트 3 — 포근한 키캡 위의 구름

방향: 키보드 제품이라는 인상을 조금 더 드러내는 부드러운 입체 안.

```text
macOS 전용 한국어 입력기 ‘하늘키보드’의 앱 아이콘을 디자인해 주세요.

1024×1024 픽셀 정사각형 PNG 원본 한 장을 만듭니다. 실제 책상이나 키보드 제품 사진을 그리는 요청이 아닙니다. 앱 아이콘만 정면에 가깝게 보여 주세요.

중앙에 둥근 모서리의 키캡 하나를 두고, 그 표면에 단순한 구름과 한글 자음 ‘ㅎ’를 크게 새긴 형태로 만듭니다. 구름 안의 글자는 정확히 ‘ㅎ’ 하나입니다. 영문 H 또는 다른 글자로 바꾸지 말고, 앱 이름이나 설명 글자는 쓰지 마세요.

키캡은 따뜻한 우윳빛 세라믹 또는 부드러운 무광 재질입니다. 구름과 ㅎ는 차분한 하늘색과 짙은 청회색으로 구분합니다. ㅎ가 배경에 묻히지 않도록 충분한 대비를 주세요. 배경은 정사각형 전체를 채우는 옅은 푸른 회색입니다.

얕은 부조와 아주 짧은 접촉 그림자로만 입체감을 표현합니다. 카메라를 크게 기울이지 말고, 키캡의 위쪽 면과 얕은 두께가 살짝 느껴지는 정도로 해 주세요. 구름과 ㅎ는 다른 장식보다 먼저 눈에 들어와야 합니다.

작은 Dock 아이콘에서도 읽히는 단순한 큰 형태를 유지합니다. 외곽 여백은 균형 있게 두고, 이미지 전체의 모서리를 미리 잘라 투명하게 만들지 마세요. 강한 광택, 반짝이, 복잡한 기계 부품, 여러 키, 작은 키보드 배열, 손, 얼굴, 풍경, 작은 글자, 워터마크, 아이콘 밖으로 길게 뻗는 그림자는 넣지 마세요.

PNG, sRGB, 1024×1024로 출력해 주세요.
```

## 모델과 도구 추천

아래는 공식 기능 설명을 확인한 뒤 **이번 작업에 맞춰 내린 추천**이다. 같은 프롬프트로 모든 모델을 직접 비교한 성능 순위는 아니다. 이용권·노출되는 모델·출력 크기는 사용하는 서비스에 따라 달라질 수 있다.

1. **GPT Image 2.5 Sunburst — 첫 추천.** 선택한 구름 모양을 유지하며 재질·여백·글자 두께를 반복 수정하는 데 우선 고려한다. 공식 문서는 편집 정밀도가 중요한 작업에 Sunburst, 빠른 일상 생성에는 Flare를 권한다. PNG 투명 배경도 지원한다. 큰 아이콘 1·3번 시안에 먼저 사용해 볼 만하다. [OpenAI 공식 이미지 생성 문서](https://developers.openai.com/api/docs/guides/image-generation).
2. **Nano Banana Pro / Nano Banana 2.** 세부 지시와 완성도를 비교하려면 Pro, 다양한 구도와 재질을 빠르게 탐색하려면 Nano Banana 2를 고려한다. Google은 Pro를 전문 자산·복잡한 지시용, Nano Banana 2를 속도·비용·성능의 균형형으로 설명한다. 1:1 고해상도 출력이 가능하다. [Google 공식 문서](https://ai.google.dev/gemini-api/docs/image-generation).
3. **Adobe Firefly의 Text to vector — 평면 로고용 대안.** 하나의 모델 순위가 아니라 SVG로 받아 Illustrator에서 선과 여백을 직접 정리할 수 있는 제작 경로다. 2번 프롬프트에 잘 맞는다. 큰 앱 아이콘의 재질 표현보다 메뉴바처럼 단순한 도형을 최종 정리할 때 특히 실용적이다. [Adobe 공식 벡터 생성 안내](https://helpx.adobe.com/firefly/web/generate-vectors/text-to-vector/generate-vectors-using-text-prompts.html).

## 결과를 고르는 기준

- 먼저 32·64px로 줄여 본다. 큰 그림보다 작은 결과를 우선한다.
- ‘ㅎ’가 정확한지, 구름과 글자가 붙거나 뭉개지지 않는지 확인한다.
- 첫 후보를 고른 뒤 색·재질·여백 중 한 가지만 바꾸어 비교한다.
- 생성한 앱 아이콘은 검토 후 적용한다. 이미 결정한 메뉴바의 구름 ㅎ는 별도 단색 자산으로 유지한다.
- 시스템의 파란 한영 전환 배경은 앱 아이콘 배경과 다르다. 그 위에서 읽히는지는 실제 IME 설치 후 따로 검증해야 한다.
