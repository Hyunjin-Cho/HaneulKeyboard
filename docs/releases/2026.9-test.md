## 함께 포함된 기존 기능

- 새 버전 발견 시 현재/최신 버전을 알리는 창. 같은 버전 자동 알림은 1회, 수동 확인은 반복 가능하다. 기존 24시간 확인을 사용하며 별도 주기 선택은 없다. 자동 설치하지 않는다.
- 업데이트 창 X/닫기 연결은 확인됐고, 실제 배경 드래그 이동은 사용자 검증이 남아 있다.
- 아트/디자인 표본 202개 중 201개 도달, 신규 39개. risograph/ransomizer 추가, surrealism 기존 지원. slab=니뮤는 한글 보호로 보류. [검역 기록](../art-design-vocabulary.md).
- 단위 표기 177개 중 단독132개/수량172개 지원. mp/MP/Mp와 12mp/12MP/12 mp/12.5mp 포함. ml/mm 단독·정상 한글 10이는 보호한다. [범위와 예외](../measurement-units.md).
- 메뉴바 처마ㅎ 단독 표시, 무료 안내, 후원 준비 중 창, 앱+IME 통합 설치/제거, 개인 사전/앱별 끄기/되돌림 규칙은 그대로다.

- [ ] 자동 변환 OFF/앱별 OFF/개인 사전 `ml` 금지에서는 숫자와 붙인 단위도 변환되지 않는다.

- [ ] 1단계에서 설치 전에 기능 시연이 보이고, 다시 보기와 동작 줄이기가 동작한다.
- [ ] 3·4단계 입력에 따라 손글씨 화살표 → 키 안내 → 결과 안내가 바뀐다. 영문 직접 입력·붙여넣기를 자동 변환 성공으로 표시하지 않는다.
- [ ] 1~5단계 모두 미색 종이·단청 처마·새 앱 아이콘이 보이고 배경 화면의 무늬는 비치지 않는다.
- [ ] 다크 모드에서는 어두운 종이에 밝은 본문이 보이고, 입력한 글자도 읽힌다.
- [ ] 일반 설정에서 Glass/Solid를 전환하면 설정·후원 창에 반영되고 안내의 종이는 유지된다. 연습 중 입력과 현재 단계가 유지되며 재실행 후 선택도 유지된다.
- [ ] 시스템의 투명도 줄이기에서는 두 스타일 모두 불투명한 배경으로 읽을 수 있다.
- [ ] 입력 소스 메뉴에서 ‘하늘’이 검정으로 표시된다. 어두운/선택 배경에서도 선명하다.
- [ ] **Caps Lock 전환 표시의 ‘하늘’이 영문 A처럼 충분히 진하고 선명하게 읽힌다.** 코드·이미지 검증만으로 해결 완료로 판단하지 않는다.
- [ ] 3단계에서 한글 모드로 `apple tangerine lychee monstera triceratops portra superia velvia`를 치고 Space를 누르면 영어로 바뀐다.
- [ ] `T800 800T a24 a16z a7r`의 등록된 이름이 변환되고 대소문자를 유지한다.
- [ ] 4단계 안내대로 `apple`을 입력하고 Shift+Space를 반복하면 `apple ↔ 메ㅔㅣㄷ`로 바뀐다. `m5` 같은 사전에 없는 조합도 단어를 확정한 뒤 양방향으로 바뀐다. 다른 되돌리기 키를 설정했다면 안내도 그 키로 표시된다.
- [ ] 3·4단계 한글 조합 중 안내 문구가 글자 뒤에 겹치지 않고, 한영 변환을 반복해도 개인 사전 카드와 창 크기가 움직이지 않는다.
- [ ] 개인 사전 예시 `hola`를 변환 추가에 등록하면 영어로 바뀐다. 시험 후 추가한 예시만 지우고 원래 개인 사전은 유지한다.
- [ ] 연습 칸에서 조합 중 글자·Backspace·커서 이동·붙여넣기·비우기가 정상이다.
- [ ] 개인 사전의 변환 추가/변환 금지를 바꾸면 입력 연습에도 반영된다. 변환 금지가 우선한다.
- [ ] 실제 입력을 한글로 되돌리면 기존 IME 규칙대로 설정의 ‘되돌린 단어’에 기록된다. 자동 시연 애니메이션은 기록을 만들지 않는다.
- [ ] 자동 변환 OFF·앱별 끄기·‘모든 단어로 확대’ OFF를 임의로 바꾸지 않고 현재 상태를 안내한다.
- [ ] 설정/개인 사전/후원 창을 실제로 열 수 있다. ‘하늘키보드 시작하기’는 준비 완료 시 안내를 닫고, 미설치·갱신 필요 시 설치 단계로 이동하며 완료로 기록하지 않는다.
- [ ] 이전·다음은 흰 글자의 인쇄 파랑, 현재 단계 점은 시안이며, 단계 이동 애니메이션 후 본문과 입력칸이 겹치지 않는다. ‘동작 줄이기’에서는 즉시 바뀐다.
- [ ] 실제 메뉴바에는 처마 ㅎ만 보이고, 메뉴를 열거나 도움말/VoiceOver로 현재 입력 언어를 확인할 수 있다.
- [ ] TextEdit·브라우저·평소 사용하는 편집 앱에서 정상 한글·영어·축약형 `don't`가 유지된다. 터미널은 수동 되돌리기 미지원이다.
- [ ] 설치/전체 제거 연동은 별도 검증한다. `설정 → 고급 → 전체 제거`는 앱과 IME를 함께 지운다. 메인 앱을 Finder에서 삭제한 경우 기존 OrphanWatcher의 지연 검사/유예가 있어 즉시 삭제를 보장하지 않는다. 메뉴바 ‘종료’는 삭제가 아니다.

삭제 시험은 재설치 수단을 확보한 뒤 별도로 수행한다. 현재 사용 중인 환경에서는 자동으로 제거 시험을 실행하지 않았다.
