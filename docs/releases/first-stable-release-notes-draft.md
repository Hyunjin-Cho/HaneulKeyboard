## 게시 본문

**베타를 마치고 첫 정식 버전을 냅니다.** 한글 모드 그대로 영어를 쓰는 기능을 크게 넓혔고, 아이콘부터 안내·설치 화면까지 리소그래프로 새로 그렸습니다.

**💻 지원: macOS Sonoma(14.0) 이상 · Apple Silicon + Intel Mac** <!-- 테스트 환경: 실기기 확인 뒤 채운다 -->

### 🎨 새 디자인 — 리소그래프로 찍은 한국의 옛 모습
- **새 앱 아이콘** — 하늘 아래 단청 처마 끝. macOS 26 이상에서는 Liquid Glass 아이콘으로 보입니다.
- **새 안내** — 일곱 단계로 설치부터 주요 기능까지 익힙니다. 3~6단계에서는 직접 쳐 볼 수 있습니다.
- **새 설치 화면(DMG)** — 같은 마을 그림 위로 앱을 Applications에 끌어다 놓습니다.
- **메뉴바 아이콘**도 처마 모양으로 바꿨습니다. 다크 모드에서는 종이가 따뜻한 먹색으로 바뀝니다.

### ⌨️ 입력
- **슬래시 영어 입력** — `/help`처럼 슬래시 뒤에는 바로 영어가 나옵니다. Space·Return·닫는 괄호 뒤나 슬래시를 지우면 한글로 돌아옵니다. Claude Code 같은 터미널 명령에 편합니다.
- **숫자는 바로** — 숫자를 누르는 즉시 들어갑니다. 터미널의 `1. Yes / 2. No` 선택지도 한글 모드 그대로 고를 수 있습니다.
- **단위와 숫자 이름** — `10kg`, `1.5kg`, `35mm`, `12mp`, `800T`, `a24`를 알아봅니다.
- **영어 + 조사** — `github에`, `API는`, `a24에서`처럼 붙여 쳐도 자연스럽게 나옵니다.
- **등록 단어 변환** — `레스토랑` → `restaurant`, `축구` → `football`처럼 등록된 한글 표기를 단축키로 영어로 바꿉니다. 다시 누르면 처음 입력한 한글로 돌아옵니다.
- **되돌리기 넓힘** — 단축키를 고를 수 있고(Shift+Space 기본), 자동으로 바뀌지 않은 단어도 직접 바꿀 수 있습니다(`ㅡ5` ↔ `m5`).
- **더 똑똑한 문맥** — 다른 입력기(ABC)로 쓴 앞 영어 단어와, 사전 단어 두 개를 붙여 쓴 영어도 알아봅니다. 둘 다 끌 수 있습니다.
- **축약형** — `i'm`, `don't`, `it's`, `you're`.
- **사전 확장** — 개발·금융·게임·의료·여행·필름/카메라·수학·생활 명사 등 수천 개를 한국어 충돌 검사를 거쳐 넣었습니다.
- **오타는 그대로** — 사전에 없는 철자는 추측해 고치지 않습니다.
- 조합 중인 글자에 노란 칠 대신 **회색 밑줄**이 그어집니다.

### 📖 개인 사전과 설정
- **개인 사전** — 변환 추가·변환 금지·최근 되돌린 변환(50개). 이 Mac에만 저장됩니다.
- **단어 제안** — 설정에서 GitHub나 메일 작성 화면을 열어 직접 보낼 수 있습니다.
- **앱별 자동 변환 끄기**와 전체 끄기.
- 설정을 **입력 기능 / 개인 사전 / 버전·업데이트 / 앱 관리** 네 메뉴로 정리했습니다.

### 🔄 업데이트·설치·제거
- **새 버전 알림** — 하루에 한 번 확인해 새 버전을 한 번 알립니다. 설치는 직접 눌렀을 때만 시작하고, 서명·Apple 공증·버전 상승을 모두 확인합니다.
- **DMG로 설치** — 첫 설치는 DMG, 이후 업데이트는 앱 안에서 합니다.
- **앱을 지우면 입력기도 스스로 정리**됩니다. 설정의 **전체 제거**는 입력기 제거가 확인된 뒤에만 개인 사전·설정을 지웁니다.
- macOS 26·27에서 입력 소스 목록에 하늘키보드가 안 보이던 문제를 고쳤습니다.
